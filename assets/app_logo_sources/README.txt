Sin Rial - Wallet Theme Logo Pack
=================================

Contenido principal:
- sin-rial-wallet-8192.png -> máxima resolución
- sin-rial-wallet-4096.png -> alta resolución
- sin-rial-wallet-1024.png -> ideal para diseño/UI
- sin-rial-wallet-original-1254.png -> archivo original generado

Archivos comunes para apps/web:
- android-chrome-192x192.png
- android-chrome-512x512.png
- apple-touch-icon.png
- icon-192.png
- icon-512.png
- favicon.ico
- favicon-32x32.png
- favicon-16x16.png

Maskable:
- maskable-icon-192.png
- maskable-icon-512.png
- maskable-icon-1024.png

Integración rápida:
1. React / Vite / PWA:
   usa icon-192.png e icon-512.png en manifest.webmanifest.
2. Capacitor / Android:
   usa sin-rial-wallet-1024.png o android-chrome-512x512.png como base.
3. iOS:
   usa apple-touch-icon.png y/o sin-rial-wallet-1024.png para exportar más tamaños.
4. Favicon web:
   usa favicon.ico.

Nota:
- El logo mantiene transparencia exterior alrededor del ícono.
- Los PNG 4096 y 8192 son ampliaciones de alta calidad del original generado.
