## Actualizaciones por GitHub Releases

La app revisa por defecto el ultimo release publico de:

```text
https://github.com/itsArtu/sin-rial-app
```

Para publicar una actualizacion:

1. Sube el numero de version en `pubspec.yaml`.
2. Compila el APK.
3. Crea un borrador de GitHub Release con tag, por ejemplo `v3.6.2+113`.
4. Adjunta el APK, su archivo `.sha256` y `latest.json` con el tamaño y hash reales.
5. Verifica los archivos antes de publicar y comprueba la descarga pública después.

Mas detalles en `release/GITHUB_RELEASES.md`.
